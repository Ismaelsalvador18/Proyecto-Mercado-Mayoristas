# Material econométrico opcional

Este directorio conserva el código de ECM, estacionariedad, rezagos y robustez que se usó en una
versión anterior del proyecto. **No forma parte del pipeline actual ni del entregable de EDA.**

El flujo principal se limita a:

1. datos;
2. panel;
3. limpieza;
4. EDA;
5. variables;
6. modelos;
7. evaluación.
